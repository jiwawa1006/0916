# 李國維 (Guowei Li) - 個人專屬網站

現代化、高質感玻璃擬態風格的個人首頁，具備動態即時時鐘、時段智慧問候與響應式互動設計。

## ✨ 特色亮點

- **個人品牌形象**：展示姓名、英文名與在線狀態。
- **動態即時時鐘儀表板**：
  - 精確至秒的即時動態時鐘（時、分、秒分別展示，秒針跳動光暈特效）。
  - 支援 **24 小時制 / 12 小時制**（AM/PM）一鍵即時切換。
  - 完整日期、星期及當年度天數計算。
  - 當日時間進度條（Day Progress Bar）。
  - 根據當前時段自動更新問候語（早安、午安、下午好、晚安、深夜提醒）。
- **深色 / 淺色模式切換**：支援一鍵切換與偏好記憶（`localStorage`）。
- **響應式現代設計**：以 CSS 自定義變數（CSS Variables）與玻璃擬態（Glassmorphism）打造，完美支援手機、平板與桌面螢幕。
- **純原生開發**：採用 HTML5、Vanilla CSS 與原生 JavaScript，無額外套件負擔，載入迅速。

## 🚀 快速開始

直接以任何瀏覽器雙擊開啟 `index.html` 即可瀏覽。

或使用任何靜態網頁伺服器：
```bash
# Python
python -m http.server 3000

# 或 Node.js
npx serve .
```
並在瀏覽器中前往 `http://localhost:3000`。

## 📁 檔案結構

```
├── index.html     # 網站結構與內容
├── style.css      # 現代玻璃擬態與排版樣式
├── script.js      # 動態時鐘、時段問候與主題切換邏輯
└── README.md      # 專案說明文件
```
